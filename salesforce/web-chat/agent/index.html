Agent Experience

Understand what happens on the service agent side when Salesforce receives and routes customer work.

What Is the Agent Experience?

The agent experience describes what happens after customer work reaches Salesforce and becomes available to a service agent.

Depending on the channel and integration, an agent may receive Web Chat conversations, voice calls, cases or other customer-service work through the Salesforce service workspace.

Agent Presence

Agent presence determines whether an agent is currently available to receive new work through Omni-Channel.

An agent can be logged into Salesforce and still be unavailable for a particular type of work if their Omni-Channel presence status does not allow new work.

  • Available — The agent can receive eligible work.
  • Busy — The agent should not receive new work.
  • On Break — The agent is temporarily unavailable.

Agent Capacity

Salesforce Omni-Channel also considers how much work an agent is already handling.

Capacity prevents Salesforce from assigning additional work when the agent has reached the configured limit.

If the agent has reached their configured capacity, new work can remain in the queue until another eligible agent becomes available.
