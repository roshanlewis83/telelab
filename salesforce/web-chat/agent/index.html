Web Chat Agent

Understand how Salesforce service agents become eligible to receive Web Chat conversations through Omni-Channel.

What is a Service Agent?

A service agent is the person who handles customer conversations and provides assistance to customers.

In Salesforce, an agent can receive customer work through Omni-Channel when the required configuration and availability conditions are satisfied.

How an Agent Receives Web Chat

A Web Chat conversation is not normally sent directly to a specific agent. Salesforce evaluates the routing configuration and determines which eligible agent should receive the conversation.

Customer → Web Chat → Routing → Queue → Omni-Channel → Agent

Agent Eligibility

An agent must meet the required conditions before Salesforce can deliver a Web Chat conversation.

These conditions can include queue membership, Omni-Channel presence and available capacity.

Queue Membership

The agent must be a member of the queue that receives the Web Chat conversation.

Queue membership identifies which agents are eligible to handle the type of work assigned to that queue.

Omni-Channel Presence

Omni-Channel presence indicates whether an agent is available to receive new work.

If an agent is offline, unavailable or otherwise not eligible to receive work, Omni-Channel will not normally deliver a new Web Chat conversation to that agent.

Agent Capacity

Omni-Channel can consider the amount of work an agent is already handling when determining whether the agent can receive another conversation.

Capacity helps prevent an agent from being assigned more work than they are configured to handle.

When the Agent Receives the Chat

When an eligible agent is available, Omni-Channel can deliver the Web Chat conversation to that agent.

The agent can then accept the work and begin communicating with the customer.

Agent and Omni-Channel

Omni-Channel acts as the delivery mechanism between customer work and available service agents.

The queue identifies the group of agents who can handle the work, while Omni-Channel determines which eligible agent should receive it.
