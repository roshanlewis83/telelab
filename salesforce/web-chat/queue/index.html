Web Chat Queue

Understand how Salesforce queues organize customer conversations and help route work to service agents.

What is a Queue?

A Salesforce queue is a group of users or agents who can receive and work on a particular type of customer conversation or work item.

Instead of sending every conversation directly to a specific agent, Salesforce can first place the work into a queue.

Why Use a Queue?

Queues help organizations distribute customer conversations among multiple service agents.

This allows Salesforce to find an eligible and available agent instead of requiring the customer to be assigned to a specific person.

How a Web Chat Reaches a Queue

When a customer starts a Web Chat conversation, Salesforce can evaluate the configured routing process and determine which queue should receive the conversation.

Queue Membership

Agents must be members of the appropriate queue to receive work that is routed to that queue.

Queue membership works together with Omni-Channel presence, routing configuration and agent capacity to determine whether an agent can receive a conversation.

Queue and Omni-Channel

A queue identifies the group of agents who can handle the work, while Omni-Channel helps determine which eligible agent should receive the conversation.

The routing process therefore connects the customer conversation, queue and available service agent.
